# Universal AI Orchestrator Foundation

This module adapts ideas from the MIT-licensed NEXUS (canoo/agent-nexus) and OrkaJS projects without copying their implementation.

## Included concepts
- provider-agnostic model registry
- capability-aware routing
- retry/fallback and health state
- specialist agents/personas
- workflow orchestration
- MCP gateway/registry boundary
- unified instructions, skills and plugin contracts

Sources:
- https://github.com/canoo/agent-nexus
- https://github.com/orka-ai/orkajs

This repository remains the integration point for the project's own implementation.
